# newsletter-generator

Client-side web application to help non-technical org members build all pieces included in monthly newsletter

# Interactive State & Logic:
Maintains an active internal state (speaker counts, sentence lists, color selections, dynamic sections) and manipulates data through JavaScript in real time

# Dynamic Document Compilation
functions as a content management tool and compiler—parsing a template, updating an in-memory DOM model via form inputs, re-rendering an isolated sandbox preview (iframe), and generating downloadable files (Blob creation).

# Serverless / Local
Does not need a remote backend or a database. Runs entirely in browser
